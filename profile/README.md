## A Note on C++

C++ gets dismissed as "too hard" or "not worth it" for general software — and for building web apps, that's fair. But for microcontrollers, embedded systems, and firmware, C/C++ is the standard. Arduino itself is written in C/C++. If you ever write code that runs close to the hardware, this is the language.
